# FreeGo

Protótipo acadêmico de uma plataforma para conectar contratantes e freelancers.

## Páginas

- `index.html`: início
- `projects.html`: projetos
- `freelancers.html`: freelancers
- `client-dashboard.html`: painel do contratante
- `freelancer-dashboard.html`: painel do freelancer
- `messages.html`: conversas
- `admin.html`: administração

As páginas compartilham a navegação e os dados de demonstração ficam no `localStorage` do navegador.
